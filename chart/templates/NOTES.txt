{{ if include "firmirror.daemonEnabled" . -}}
To check the daemon:

  kubectl get deployment {{ include "firmirror.fullname" . }} -n {{ .Release.Namespace }}

To view its logs:

  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "firmirror.fullname" . }} --tail=100

{{ if (.Values.bkc | default dict).url -}}
It publishes the metadata again when the rollout rings change.

{{ end -}}
It serves Prometheus metrics on port {{ include "firmirror.metricsPort" . }} at /metrics.

{{- if .Values.signing.enabled }}

It signs with the keys as the Secret holds them at each publish, and signs an unchanged
document again only at startup, so to publish with a new key without waiting for a change
restart it:

  kubectl rollout restart deployment/{{ include "firmirror.fullname" . }} -n {{ .Release.Namespace }}
{{- end }}
{{- else -}}
To check the status of your CronJob:

  kubectl get cronjob {{ include "firmirror.fullname" . }} -n {{ .Release.Namespace }}

To view recent jobs:

  kubectl get jobs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component!=regen

To manually trigger a job now:

  kubectl create job --from=cronjob/{{ include "firmirror.fullname" . }} {{ include "firmirror.fullname" . }}-manual-$(date +%s) -n {{ .Release.Namespace }}

{{- if include "firmirror.regenEnabled" . }}

To publish the metadata again although nothing was mirrored, for example for a new signing key, or for new rollout ring definitions before the next refresh does:

  kubectl create job --from=cronjob/{{ include "firmirror.regenName" . }} {{ include "firmirror.regenName" . }}-$(date +%s) -n {{ .Release.Namespace }}

Do not start it while a refresh is running.
{{- end }}

To view logs from the latest job:

  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component!=regen --tail=100
{{- end }}

{{- if .Values.persistence.enabled }}

To access the firmware repository data:

  kubectl exec -it -n {{ .Release.Namespace }} <pod-name> -- ls -lh {{ .Values.storage.outputDir }}
{{- end }}
